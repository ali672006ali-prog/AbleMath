## 📖 About

AbleMath is an Arabic-only educational game built for 4th-grade special education students (intellectual disabilities) at El-Bagour schools. Through visual aids and playful interaction, students learn:

- 🔢 The number **100** and what it means
- ➕ Counting by **tens** up to 100
